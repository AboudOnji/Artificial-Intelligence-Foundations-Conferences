## Overview
Welcome to the **Artificial Intelligence Foundations** repository. This collection serves as a comprehensive resource for understanding the core concepts, mathematical models, and practical implementations of various AI domains. The materials range from classical search algorithms to advanced computational intelligence techniques.

## Course Content
The course covers a wide spectrum of Artificial Intelligence topics, structured to provide both theoretical understanding and practical skills:

- **Search Algorithms**: Uninformed and informed search strategies, optimization techniques.
- **Evolutionary Computation**:
    - Genetic Algorithms
    - Evolutionary Strategies in Industrial Engineering
- **Fuzzy Logic**:
    - Fuzzy Sets and Systems
    - Tree Fuzzy Inference Systems
- **Machine Learning**:
    - Supervised and Unsupervised Learning
    - Regression Models
    - Classification Techniques
- **Neural Networks (ANN)**:
    - Artificial Neurons and Architectures
    - Deep Learning Foundations
- **Swarm Intelligence**:
    - Particle Swarm Optimization (PSO)
    - Multi-Objective PSO (MOPSO)
- **Natural Language Processing (NLP)**: Text processing and linguistic analysis.
- **Artificial Immune Systems**: Bio-inspired algorithms for optimization and security.

## Repository Structure
This repository is organized into specific folders for each topic, containing:

- **Conferences & Presentations**: LaTeX presentations (`.tex`) and materials illustrating theoretical concepts.
- **Examples**: Practical implementations and code snippets to demonstrate the algorithms.
